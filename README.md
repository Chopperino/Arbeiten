# Arbeiten
Мета Arbeiten - спростити процес працевлаштування для користувачів та забезпечити зручний інтерфейс для зв'язку між кандидатами і роботодавцями.

## Опис структури проєкту
Бекенд (папка backend) створений за допомогою TypeScript. Всередині знаходяться конфігураційні файли (.json, .env.example), 
Prisma Schema для налаштування взаємодії з базою даних і визначення основних моделей та папка з основною частиною бекенду - src.
В src розташовані файли .ts, розбиті на папки відповідно до Three-Layer Architecture: controllers, dtos, exceptions, mappers, middlewares, repositories, 
responses, routes, services і types.
Бекенд піднімає локальний сервер, надає інструменти для взаємодії із сутностями у базі даних та навігації по сайту, оброблює API-запити.

Фронтенд (папка frontend) створений за допомогою JavaScript, бібліотеки React.js та HTML/CSS. Він надає інтерфейс для взаємодії користувача з інструментами
сайту - профілем, вакансіями тощо, взаємодіє з бекендом за допомогою API-запитів.

## Ролі членів команди
- Керівник проєкту: Вінницький Артем.
- Фронтенд-розробники: Поліщук Дарія та Купрій Марина.
- Бекенд-розробники: Вінницький Артем та Оверченко Володимир.
- Розробники БД: Вінницький Артем та Оверченко Володимир.
- Тестувальники: Поліщук Дарія та Купрій Марина.
