# Arbeiten
Мета Arbeiten - спростити процес працевлаштування для користувачів та забезпечити зручний інтерфейс для зв'язку між кандидатами і роботодавцями.

## Опис структури проєкту
Проєкт складається з бекенду на TypeScript і фронтенду на React.

Бекенд побудований за принципами RESTful архітектури і реалізований на основі фреймворку Express.js з використанням Three-Layer Architecture для структуризації коду. База даних PostgreSQL управляється через Prisma ORM. Авторизація та аутентифікація користувачів виконується за допомогою JWT (JSON Web Token).
Основну частина бекенду - файли .ts, папка src - розділено на модулі: controllers, dtos, exceptions, mappers, middlewares, repositories, responses, routes, services і types.

Фронтенд (папка frontend) створений за допомогою JavaScript, бібліотеки React.js та технологій стилізації HTML/CSS.

## Інструкції для запуску програми
1. Склонуйте репозиторій: `git clone https://github.com/Chopperino/Arbeiten.git`
2. Встановіть залежності: `cd backend` <br> `npm install`
3. Налаштуйте змінні у файлі .env
4. Запустіть сервер: `npm run dev`
